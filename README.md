# 秋招投递管理看板

一个**单文件、纯本地**的秋招投递管理工具。记录投了哪些公司、什么岗位、进度到哪一步，支持表格和看板两种视图，改状态自动更新统计。

- 零依赖：一个 HTML 文件，双击浏览器打开就能用
- 不联网：没有后端，没有登录，数据只存在你自己的浏览器里
- 不需要安装任何东西，不存在"服务挂了用不了"的问题

## 功能

**两种视图，右上角一键切换**

- **表格视图**：一行一条投递，11 列（企业 / 性质 / 投递岗位 / 优先级 / 状态 / 所在地 / 投递时间 / 下个节点 / 链接 / 备注 / 操作）。按金融 / 国央企 / 互联网三类分组，组头显示"N 条 · 进行中 M"
- **看板视图**：六列状态卡片（已投递 / 笔试中 / 面试中 / 已 Offer / 已挂 / 放弃），**拖拽卡片直接改状态**

**录入与修改**

- 新增投递：弹窗表单，公司 + 岗位必填，支持企业性质、状态、优先级、所在地、投递日期、下个节点、链接、备注
- 表格里**状态列是下拉框，直接改，不用进弹窗**
- 点行任意位置也能打开编辑；可删除（有二次确认）
- 优先级 P1 / P2 / P3

**筛选与查找**

- 顶部三个分类卡：金融 / 国央企 / 互联网，点一下就只看那一类
- 快捷筛选：全部 / 进行中 / 7 日内截止 / 已 Offer
- 搜索框：按公司、岗位、备注、城市实时过滤
- 点列头排序，再点反向

**自动提醒**

- 顶部橙色紧急条：自动列出 3 天内截止的投递，点一下直接编辑
- 3 天内截止的行浅红底，4-7 天浅黄；已挂 / 放弃整行置灰

**统计**

- KPI：总投递 / 面试转化率 / 已 Offer 数 / 7 日内截止
- 分类统计卡：每类的总数、进行中、Offer 数
- 申请漏斗：六个状态的数量分布

**数据**

- 所有改动自动保存到浏览器 `localStorage`，关掉重开还在
- 导出 JSON / 导入 JSON，换电脑用

## 使用

1. 下载 `index.html`
2. 双击用浏览器打开
3. 把示例数据替换成你自己的（点行编辑，或直接删了新增）
4. 之后每次打开就是上次的样子

## 为什么不做账号系统

数据存在浏览器本地，只有你能看到。做登录注册需要后端和数据库，是个完全不同量级的工程，还会引入"服务器挂了数据没了的风险"。本地文件 + 导出备份，对这个场景够用且更可靠。如果想要多设备同步，导出 JSON 手动传一下即可。

## 数据安全

- 所有数据保存在浏览器本地，不上传任何服务器
- **仓库里的示例数据全部为虚构内容**（公司名用"某某"占位）
- **注意：如果你在本地填了真实投递信息，这个文件就不能直接公开分享** —— 数据是明文的，上传前请先清空或换成示例数据
- 导出的 JSON 同样是明文，含真实信息时不要放进公开仓库

## 浏览器要求

任何现代浏览器均可（Chrome / Edge / Safari / Firefox）。拖拽功能需要支持 HTML5 Drag and Drop 的浏览器。
